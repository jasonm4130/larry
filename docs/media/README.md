# Demo media

Drop demo assets here, then wire them into the top of the root `README.md`
(replace the `<!-- DEMO ... -->` placeholder).

For a physical, voice-driven project this is the single highest-leverage thing
a visitor can see. Worth capturing:

- **Hero still** — `hero.jpg`: the skull on a desk, good lighting. Used as the
  social/preview image.
- **Jaw-sync clip** — `demo.mp4` (or a sub-5MB `demo.gif`): 10–20s of a real
  "Hey Larry → reply" exchange, framed so the jaw movement is visible in time
  with the voice. This is the payoff shot.

Embedding:

- GitHub renders a **drag-dropped `.mp4`** inline in the README editor — easiest path.
- Or reference a file: `![Larry in action](docs/media/demo.gif)`.
- Keep GIFs under ~5MB so they autoplay; prefer MP4 for anything longer.
